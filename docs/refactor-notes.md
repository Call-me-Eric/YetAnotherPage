# 底层修正记录

这份记录描述本次检查确认的问题与实际修正，不代表整个软件已经没有缺陷。原有未提交修改保留在当前工作区中，没有自动提交或推送。

## 数据与历史

1. **异步文字保存覆盖新笔画或撤销结果**：先同步更新内存对象，后台仅保存操作快照；保存完成不能回写整份旧笔记。位置：`note_page.dart`。
2. **写入队列读取可变的最新状态**：每次提交捕获对应快照，避免旧删除再次套到后来的撤销上。
3. **退出后排队保存被跳过**：去掉保存任务中的 mounted 放弃判断；正常退出等待写入完成。保存失败时留在编辑页。
4. **一次保存失败阻断整个后续队列**：`WriteQueue` 保留失败任务，重试成功前不允许较新的任务越过它。
5. **重命名、删页、改图层、删除笔记与写入竞争**：结束编辑、排空写入后再执行结构操作；执行期间阻止继续编辑，避免返回旧结构或重新创建已删除目录。
6. **套索取出与贴回被分成两个撤销步骤**：取出只改变显示事务，贴回一次记录原对象与最终对象。撤销/重做不会停在笔迹消失的中间状态。
7. **粘贴沿用上次选择的原始 id**：剪贴板产生的新贴图没有原笔画 id，避免粘贴命令意外删除之前选中的内容。
8. **文字框创建没有历史项**：创建纳入统一撤销栈；文字修改、删除和移动继续使用统一历史。
9. **文字编辑改变对象堆叠顺序、版本不一致**：替换原位置的文字对象；内容或尺寸真正变化才增加版本，重复保存不再重复增加。
10. **完成笔画仍共享可变点列表**：`StrokeObject` 在 finalized 时复制并冻结列表，缓存和保存不再依赖能被外部修改的几何。
11. **同一批添加的重复 id 未去重**：内存与磁盘添加都用更新中的 known 集合去重。

## 橡皮与绘制

12. **橡皮显示半径与命中半径不一致**：两种橡皮的命中和裁切都使用当前设置半径。
13. **区域橡皮等抬笔才真正改变对象**：落笔与移动立即更新片段，抬笔只记一次完整历史；片段保留原对象的堆叠位置。
14. **只索引端点会漏掉长线段中央**：空间索引覆盖实际线段及笔宽，使用二元组桶键避免坐标编码碰撞。
15. **对象橡皮用白色覆盖制造淡化**：直接对对象的绘制结果整体降低透明度，边缘与内部一致，不再洗白交叉的上方笔画。
16. **删除导致清空整页瓦片、过渡重复重绘**：保留其他瓦片及受影响瓦片的其他像素，只在受影响矩形中重建；过渡矢量与新图在同一帧交接，旧代异步结果丢弃。
17. **完成笔画不断重新提交大量线段**：缓存不可变笔画的矢量绘制指令与边界；重建复用缓存。屏幕外页面只保留尺寸占位。
18. **文字始终绘制在全部墨迹之上**：按图层及对象顺序交错绘制文字与墨迹，实时笔画也位于正确的可写层。
19. **文字草稿绕过隐藏或墓碑过滤**：草稿也检查所属页、图层可见状态及删除标记。
20. **长笔画拟合出现累计数值误差**：局部窗口时间归零并换成毫秒，避免累计时间高次项相减。已有完成笔画不重新拟合。

## 持久化与文档

21. **持续写盘要求未落实**：加入可选 `StrokeRecoveryStore` 接口，追加原始采样日志；正式提交后移除日志，打开时恢复完整记录，截断尾行不影响前面的样本。旧日志不能复活已存在或已墓碑对象。
22. **每次编辑扫描整层笔画文件**：`changeMarks` 仅处理本次新增笔画；已有完成文件不变，未完成旧草稿可以更新。
23. **文件替换失败先删旧文件**：唯一临时文件、POSIX 原子替换，Windows 备份与失败回滚；不因任意替换错误直接删除原件。
24. **笔画引用缺文件时静默跳过**：打开时报明确错误，避免将少了笔画的数据再次保存。
25. **README 与开发者手册描述旧实现**：更新工具栏、套索、恢复日志、历史事务及局部缓存说明。

## 验证范围

回归测试覆盖：真实编辑流程的区域擦除、套索移动的单步撤销/重做、慢保存与新笔画/撤销交错、退出等待写入、交叉笔画擦除与后续墨水的像素检查、长笔画时间偏移、不可变几何、文件重复添加、日志截断恢复和旧日志不复活对象、文字版本与顺序、并发原子写。

平台构建分别检查 iOS 无签名版本、macOS release 和 Android debug。Windows/Linux 尚未在对应系统实际构建；Apple Pencil 震动、悬停、实际高频采样和大量笔画的帧率仍需要真机验证。本次并未实现原生合并触点/Android 历史采样接入，也不声称帧率测试通过。增量日志只保证已写盘的完整记录可恢复，不能保证程序强杀时还在内存或等待 I/O 的样本。
